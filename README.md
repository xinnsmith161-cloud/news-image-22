A one-page newspaper front page summing up Sunday, 22 November 2026: COP31 climate talks near a deal in Antalya, coalition talks opening in Israel, the ATP Finals decider in Turin, and a magnitude 4.1 earthquake in Myanmar. Every story was checked against reporting dated 22 November 2026. The page is drawn with Python (PIL) by `draw_news.py`; `main.ts` copies the finished `entry.png` to `/output/entry.png`.

## Run it

```sh
python3 draw_news.py
node main.ts
```
